# ULPF Production Failure & Recovery Matrix

This matrix documents exact failure scenarios, system detection mechanisms, automatic fallbacks, recovery steps, and evidence guarantees across all operational subsystems.

| Subsystem / Scenario | Trigger Condition | System Detection & Handling | Automated Recovery Behavior | Operator Playbook Action | Data Loss Guarantee |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Backend Process Crash** | Unexpected SIGKILL or host reboot during high ingestion. | SQLite WAL mode journal recovery; raw JSONL was written with flush. | Upon restart, SQLite WAL auto-recovers uncheckpointed transactions; Merkle root recalculates from disk. | Execute `systemctl restart ulpf` or restart container. | **Zero loss:** All flushed events are preserved in `lossless_archive.jsonl`. |
| **Malformed / Corrupted Wire Input** | Attackers transmit non-printable bytes or truncated headers. | Parser regex fails match; `quarantine_manager` intercepts failure. | Event routed to `storage/quarantine.db` with status `PENDING` and category `MALFORMED_SYNTAX`. | Inspect event in UI Quarantine Viewer; dismiss or edit parser. | **Zero loss:** Pristine wire bytes preserved in quarantine database. |
| **Catastrophic Regex Bomb (ReDoS)** | Operator uploads malicious candidate pack containing nested quantifiers. | `SourcePackLifecycleManager.audit_regex_safety()` inspects pattern. | Promotion rejected immediately with error; previous active version remains in memory. | None required; invalid pack is blocked before compilation. | **Zero loss:** Pipeline unaffected. |
| **High Burst Volume (Queue Overflow)** | Ingestion volume exceeds worker throughput (e.g. 50k EPS burst). | `IngestionQueueManager.is_backpressure_active` trips at 85% depth. | Enqueue triggers flow control throttling (returns HTTP 429); drops excess events only when buffer hits 50,000 slots. | Scale additional worker nodes behind L4 HAProxy. | **Bounded loss:** Memory protected from OOM crashes; buffer absorbs bursts. |
| **Vendor Firmware Upgrade (Parser Drift)** | Upstream firewall alters key names (e.g. `src` $\to$ `source_ip`). | `DriftDetector` detects rolling field null-rate spike (>20%). | System emits `DRIFT_DETECTED` SSE alert; samples events to Learning Path for candidate pack synthesis. | Review and approve candidate pack in Web UI. | **Zero loss:** Unmatched events preserved in raw archive and quarantine. |
| **Defective Parser Promoted to Production** | Newly promoted pack introduces false negatives in live traffic. | SRE/SOC notices error spike or quarantine volume surge. | Operator executes `POST /api/source-packs/rollback`. System atomically swaps previous version in `<2 ms`. | Call `/api/source-packs/rollback` with target version. | **Zero loss:** Quarantined events replayed via `/api/quarantine/replay`. |
| **Digital Evidence Tampering** | Insider modifies byte in `lossless_archive.jsonl`. | Merkle audit proof verification recalculates leaf `SHA-256(0x00 || raw)`. | Merkle Root Hash comparison fails; system emits `TAMPER_DETECTED: ROOT_HASH_MISMATCH`. | Flag evidence as compromised; isolate log host for forensic audit. | **Tamper Evident:** Single-byte alteration mathematically exposed. |
| **Outbound Cloud Telemetry Attempt** | Third-party dependency attempts outbound DNS/HTTP call. | `egress_guard.py` socket monkey-patch intercepts `socket.connect`. | Process immediately raises `PermissionError (EPERM)`; socket connection aborted. | None; fail-closed air-gap defense enforced. | **Zero leak:** Outbound packets never hit network wire. |
